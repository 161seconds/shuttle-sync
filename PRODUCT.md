# ShuttleSync

## Product Description
ShuttleSync is a premium sport booking platform (specializing in badminton, pickleball, etc.). It provides a comprehensive ecosystem for users to search for courts, book time slots, find group play partners, use AI coaching features, and stay updated with live sports news.

## Target Audience
Athletes, casual sports players, and court owners who demand a seamless, highly functional, yet visually stunning booking experience. 

## Surface Type
**Product (App UI / Dashboard / Tool)**
While ShuttleSync contains high-end "Brand" visual elements (like 3D interactive splash screens and particle fields), its core is a highly interactive Web App. 
UX clarity, data hierarchy, and frictionless user flows must take precedence over pure visual flair in the core booking and dashboard screens.

## Voice & Tone
- **Professional yet Energetic**: The copy should motivate users to play sports while maintaining trust for transactions.
- **Concise**: No fluff in the UI. Keep labels short and actionable.
